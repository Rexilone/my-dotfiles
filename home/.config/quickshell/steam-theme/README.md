# Тема Steam «Rexilone»

Тема для клиента Steam в стиле Rexilone Shell: те же цвета, шрифт, скругления, переключатели,
меню и навигация, что в баре и Настройках шелла. Все функции Steam на месте: тема меняет
только внешний вид.

Цвета и шрифт берутся из шелла. При смене схемы (тёмная, светлая, Nord, «под обои» и т. д.)
Steam перекрашивается сам, без перезапуска.

## Что оформлено

- **Главное окно.** Слева узкая панель иконок: Магазин, Библиотека, Сообщество, Профиль,
  внизу Загрузки, Друзья, Добавить игру, Настройки. Названия появляются в подсказке при наведении.
  Это настоящие вкладки и кнопки Steam, только переставленные. Подменю вкладок (Рекомендации,
  Список желаемого…) открывается **правым кликом** по иконке: при наведении оно закрывало бы
  соседние иконки. Нижней полосы больше нет. Сверху меню Steam/View/… и кнопки аккаунта.
- **Библиотека.** Список игр как навигация в Настройках, поиск, коллекции, полки,
  страница игры с кнопкой «Играть», загрузки.
- **Окна.** Меню, подсказки, карточки игр при наведении, уведомления.
- **Диалоги.** Настройки Steam и свойства игры: карточки, переключатели, галочки, кнопки, списки.
- **Друзья и чат.** Список друзей и окна чата. Статусы «в сети» и «в игре» окрашены цветами
  палитры терминала текущей схемы.
- **Магазин и сообщество.** Это сайты, поэтому оформлены только фон, верхняя панель магазина с поиском, скроллбары и выделение.

## Как устроено

Steam рисует интерфейс веб-движком. [Millennium](https://github.com/SteamClientHomebrew/Millennium)
подключает в его окна CSS и JS темы.

Классы Steam зашифрованы (`_3Z7VQ1IMk4E3HsHvrkLNgo`) и меняются с обновлениями клиента.
Поэтому `theme.css` и `friends.css` пишутся с понятными именами:

```css
.%TopBar% { … }                               /* класс TopBar из модулей Steam */
.%Container@GameListHomeAndSearch% { … }      /* Container из модуля, где есть GameListHomeAndSearch */
```

`qs-loader.js` в каждом окне находит в webpack-модулях Steam настоящие классы, подставляет их
и вставляет стиль. Раз в 2 секунды он перечитывает файлы: правки CSS и новые цвета
применяются сразу.

| Файл                    | Что это                                                        |
|-------------------------|----------------------------------------------------------------|
| `theme.css`             | главное окно, библиотека, меню, диалоги                        |
| `friends.css`           | список друзей и чат                                            |
| `webkit.css`            | магазин и сообщество (фон, скроллбары)                         |
| `colors.css`            | цвета и шрифт; **генерирует шелл**, в git не хранится          |
| `qs-loader.js`          | загрузчик: имена классов → настоящие классы, живая перезагрузка |
| `rail.js`               | подсказки на панели, пункт «Настройки», подменю по правому клику |
| `*.custom.js/css`       | точки входа, которые подключает Millennium                     |
| `skin.json`             | описание темы для Millennium                                   |
| `install.sh`            | подключить тему (ссылка + выбор в конфиге Millennium)          |

## Установка

### Arch

```sh
paru -S millennium-bin                          # или millennium из AUR
steam -shutdown
~/.config/quickshell/steam-theme/install.sh
steam
```

### NixOS

У Millennium есть свой flake с пакетом `millennium-steam` (это Steam с Millennium внутри):

```nix
# flake.nix
inputs.millennium.url = "github:SteamClientHomebrew/Millennium?dir=packages/nix";

# configuration.nix
nixpkgs.overlays = [ inputs.millennium.overlays.default ];
programs.steam = {
  enable = true;
  package = pkgs.millennium-steam;
};
```

Потом подключи тему: через `install.sh` или декларативно, например в Home Manager:

```nix
home.file.".local/share/Steam/millennium/themes/rexilone".source =
  config.lib.file.mkOutOfStoreSymlink "${config.home.homeDirectory}/.config/quickshell/steam-theme";
```

Здесь нужна именно ссылка «вне store»: шелл пишет в эту папку `colors.css`.
Тему один раз выбери в Steam: **Millennium → Themes → Rexilone**.

## Если после обновления Steam что-то стало старым

Значит, Valve переименовали класс в своих модулях. Список не найденных имён показывает
консоль окна Steam: `[rexilone] нет классов: …`. Новое имя можно подставить в CSS.
